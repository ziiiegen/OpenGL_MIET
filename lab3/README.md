## Файлы

- `objects.py`: стол, книга, ручка, чайник и случайная расстановка на одном столе.
- `audience.py`: 3 ряда по 4 стола, пол, стена с доской и отражение аудитории.
- `main.py`: окно, камера, три проекции, отсечение и обработка клавиатуры.
- `test.py`: прежний первый пример с пустым окном GLUT.

## Управление

| Клавиша | Действие |
| --- | --- |
| `1` | Параллельная проекция `glOrtho` |
| `2` | Перспектива `gluPerspective` |
| `3` | Перспектива `glFrustum` |
| `W` / `S` | Приблизить / удалить камеру, изменяя параметры `gluLookAt` |
| `A` / `D` | Повернуть камеру вокруг сцены |
| `M` | Показать / скрыть отражение; подобрать обзор для одной или двух аудиторий |
| `C` | Включить / выключить демонстрацию отсечения |
| `[` / `]` | Уменьшить / увеличить расстояние до ближней плоскости на 1 |
| `,` / `.` | Уменьшить / увеличить расстояние до дальней плоскости на 1 |
| `N` | Создать новые случайные позиции, повороты и цвета книг |
| `R` | Вернуть исходную камеру, перспективу и полные границы отсечения |
| `Escape` | Закрыть программу |

Вверху окна показаны текущие проекция, расстояние камеры и значения `near`/`far`.

## Как показать все пункты задания

1. Запусти `main.py`: видны аудитория и её отражение, разделённые стеной с доской.
   Настоящая аудитория содержит 3 ряда вдоль Z, по 4 стола вдоль X в каждом.
   На каждом столе лежат книга и ручка и стоит чайник. Всего 12 настоящих столов.
2. Нажми `M`, чтобы рассмотреть только настоящую аудиторию. Нажми `N` несколько
   раз: положение и поворот предметов и цвет каждой книги изменяются случайно.
   При обычной перерисовке они сохраняются. Предметы помещаются на столах
   и не пересекаются друг с другом.
3. Сравни режимы `1`, `2`, `3`. В параллельной проекции одинаковые предметы
   сохраняют одинаковый размер независимо от глубины. В перспективе удалённые
   предметы выглядят меньше. Режимы `2` и `3` настроены на одинаковую перспективу.
4. В режиме `2` нажми `W` и `S`: камера движется по направлению к центру сцены
   и обратно. В режиме `1` камера тоже перемещается, но размеры объектов
   не меняются: это свойство ортографической проекции, а не ошибка управления.
5. Нажми `C`: ближняя и дальняя плоскости проходят через занятую объектами
   часть сцены. Части столов и предметов за этими границами отсекаются.
   Клавишами `[` / `]` и `,` / `.` двигай плоскости самостоятельно.
   Нажми `C` снова или `R`, чтобы вернуть весь объём видимости.
6. Нажми `M`, чтобы снова увидеть отражение. Используй `A` / `D` для другого
   ракурса. В оригинале и отражении сохранены одинаковые предметы и цвета.

## Что объяснить на защите

Объекты сначала рисуются в своей локальной системе координат. Для размещения
на столе и в аудитории используются переносы и повороты. `glPushMatrix` и
`glPopMatrix` сохраняют и восстанавливают матрицу, чтобы преобразование одного
объекта не изменяло другие.

Для `gluPerspective` задаются угол обзора, отношение ширины окна к высоте,
ближняя и дальняя плоскости. `glFrustum` позволяет напрямую задать левую,
правую, нижнюю и верхнюю границы на ближней плоскости. В программе они
вычисляются через `near * tan(FOV / 2)`, поэтому обе перспективы эквивалентны.
`near` и `far` задаются положительными, и всегда выполняется `near < far`.

Отсечение выполняет сам OpenGL после применения матрицы проекции.
При увеличении `near` отсекаются близкие части сцены; при уменьшении `far` —
дальние. Объекты не скрываются вручную: OpenGL обрезает их геометрию.

Стена находится в плоскости `z = WALL_Z`. Для отражения используются:

```python
glTranslatef(0.0, 0.0, WALL_Z)
glScalef(1.0, 1.0, -1.0)
glTranslatef(0.0, 0.0, -WALL_Z)
```

OpenGL умножает текущую матрицу справа, поэтому к вершине эти преобразования
применяются в обратном порядке. Получается `z' = 2 * WALL_Z - z`, а `x` и `y`
сохраняются. Точки самой плоскости остаются на месте. Стена полупрозрачна,
чтобы можно было рассмотреть всю отражённую аудиторию.

## Первые заметки о GLUT

`glutInit(sys.argv)` - инициализируемся (подготавливаемся)

`glutInitDisplayMode(GLUT_DOUBLE | GLUT_RGB)` - Двойная буферизация означает, что программа сначала рисует кадр в невидимой области памяти, а затем целиком показывает его. Благодаря этому изображение не мерцает.

`glutInitWindowSize(800, 600)` - Задаем размер окна

`glutCreateWindow(b"TEXT")` - Создаем окно

`glClearColor(0.2, 0.3, 0.4, 1.0)` - Фон или каким цветом мы будем очищать оуно.
