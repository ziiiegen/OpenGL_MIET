# Лабораторная №3

## Запуск

```powershell
cd D:\university\ComputeGraphics
.\.venv\Scripts\python.exe .\lab3\main.py
```

Используются установленные в `.venv` PyOpenGL и FreeGLUT.

## Управление

- `1` — `glOrtho`, параллельная проекция.
- `2` — `gluPerspective`, перспективная проекция.
- `3` — `glFrustum`, перспектива через границы ближней плоскости.
- `C` — включить/выключить обрезание дальней части сцены.
- `W` / `S` — приблизить/удалить камеру через `gluLookAt`.

Раскладка английская. Выход — закрыть окно.

## Код и объяснение для защиты

- `objects.py`: стол — крышка и четыре ножки из кубов; книга — один растянутый куб; ручка — один цилиндр; чайник — `glutSolidTeapot`.
- `scene.py`: три ряда по четыре стола и их отражение. `random.seed(1)` задаёт повторяемую случайную расстановку: предметы не прыгают при перерисовке, а отражение совпадает с оригиналом. Контур стены с доской обозначает плоскость отражения `z = -7`.
- `main.py`: окно, проекции и приближение/удаление камеры.

`glPushMatrix` сохраняет матрицу, `glPopMatrix` возвращает её. Поэтому преобразование одного предмета не влияет на следующий.

При вызовах переноса, поворота и масштаба получается `M = T · R · S`; к вершине первым применяется масштаб, затем поворот, затем перенос.

Отражение: `T(0,0,-7) · S(1,1,-1) · T(0,0,7)`, то есть `z' = -14 - z`. Аудитория рисуется повторно с этой матрицей.

Обрезание включается уменьшением `far` — расстояния до дальней плоскости видимости. `gluLookAt` задаёт положение глаза, точку наблюдения и направление вверх. При `glOrtho` удаление камеры не меняет размер предметов; при перспективе меняет.
