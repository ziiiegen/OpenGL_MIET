# Лабораторная работа 3

Основная программа состоит из двух файлов:

- `objects.py` — функции рисования стола, книги, ручки и чайника. У каждой есть параметр `color` с цветом по умолчанию. Вспомогательная `draw_box` рисует растянутый куб и тоже принимает цвет.
- `main.py` — случайные данные, аудитория, проекции, камера и отражение. В нём четыре функции: `draw_audience`, `display`, `reshape`, `keyboard`.

`test.py` оставлен как прежний пример создания пустого окна, основная программа его не использует.

## Запуск

```powershell
& "D:\university\ComputeGraphics\.venv\Scripts\python.exe" "D:\university\ComputeGraphics\lab3\main.py"
```

Нужны PyOpenGL и freeglut, которые уже установлены в окружении проекта.
Используй английскую раскладку клавиатуры.

## Управление

| Клавиша | Действие |
| --- | --- |
| `1` | Параллельная проекция `glOrtho` |
| `2` | Перспектива `gluPerspective` |
| `3` | Та же перспектива через `glFrustum` |
| `W` / `S` | Приблизить / удалить камеру через `gluLookAt` |
| `C` | Включить / выключить обрезание ближней и дальней плоскостями |
| `M` | Показать / скрыть отражение |
| `Esc` | Закрыть окно |

При запуске видны 12 настоящих столов и их зеркальная копия. Доска находится
в плоскости `z = -6`. Саму стену не рисуем, поэтому она не закрывает отражение.

## Как устроен код

В `objects.py` предметы создаются в локальных координатах: стол стоит на
`y = 0`, его верх находится на `y = 1.4`. Нижние поверхности книги, ручки и
чайника находятся на `y = 0`, поэтому в аудитории их поднимаем на `1.4`.

`draw_audience` рисует столы двумя вложенными циклами: 3 ряда по 4 стола.
Для каждого предмета сохраняет матрицу через `glPushMatrix`, выполняет перенос
и поворот, рисует предмет и возвращает матрицу через `glPopMatrix`.

Позиции предметов создаются один раз перед запуском окна. Столешницу условно
делим на три участка с центрами X = -1, 0, 1. Случайно перемешиваем эти места
между книгой, ручкой и чайником, затем добавляем случайные смещения и повороты.
Для выбранных размеров предметы остаются на столе и не пересекаются.
У каждой книги свой сохранённый случайный цвет. При перерисовке и отражении
позиции и цвета сохраняются. Новую расстановку получаем перезапуском программы.

Проекция задаётся в `GL_PROJECTION`, камера и преобразования объектов —
в `GL_MODELVIEW`. `glOrtho` сохраняет размер предметов независимо от глубины.
В перспективе дальние предметы выглядят меньше. Для `glFrustum` границы
ближней плоскости вычисляются через `near * tan(45° / 2)`, поэтому режимы
`2` и `3` дают одинаковое изображение.

`W` и `S` меняют положение камеры, передаваемое в `gluLookAt`. В режиме
`glOrtho` камера тоже перемещается, но размер предметов не меняется.

При `C` вместо широкого диапазона `near = 0.1`, `far = 120` задаётся диапазон
от `camera_distance - 6` до `camera_distance + 6`. OpenGL обрезает части
геометрии, выходящие за эти плоскости. Нажми `C` снова, чтобы вернуть сцену.

Отражение — повторное рисование той же аудитории после преобразований:

```python
glTranslatef(0, 0, wall_z)
glScalef(1, 1, -1)
glTranslatef(0, 0, -wall_z)
```

К вершине они применяются снизу вверх: перенос плоскости в ноль, смена знака Z,
возврат плоскости. Получается `z' = 2 * wall_z - z`; X и Y сохраняются.

## Проверка задания

1. Нажми `M`: остаётся аудитория из 3 рядов по 4 стола с тремя предметами на каждом.
2. Сравни `1`, `2`, `3`, затем попробуй `W` и `S`.
3. Нажми `C`: часть столов и предметов будет обрезана. Отключи `C`.
4. Включи `M`: отражение повторяет положения и цвета предметов.

## Первые заметки о GLUT

`glutInit(sys.argv)` — подготавливаем GLUT.

`glutInitDisplayMode(GLUT_DOUBLE | GLUT_RGB)` — рисуем в невидимом буфере,
а затем показываем готовый кадр, чтобы изображение не мерцало.

`glutInitWindowSize(800, 600)` — задаём размер окна.

`glutCreateWindow(b"TEXT")` — создаём окно.

`glClearColor(0.2, 0.3, 0.4, 1.0)` — задаём цвет фона.
