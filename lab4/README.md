# Лабораторная №4 — текстуры

На столе стоят глобус и зеркальная сфера одинакового радиуса 0.67.
Комната, стол и глобус используют обычные PNG-текстуры.
У зеркальной сферы включён GL_SPHERE_MAP для автоматических координат текстуры.

## Порядок запуска

1. Запусти make_environment.py: он сохранит textures/environment.png.
2. Запусти main.py: он загрузит готовую картинку и покажет сцену.

```powershell
cd D:\university\ComputeGraphics
.\.venv\Scripts\python.exe .\lab4\make_environment.py
.\.venv\Scripts\python.exe .\lab4\main.py
```

Можно запускать оба файла по очереди из своей среды разработки с окружением
проекта. Используются PyOpenGL, FreeGLUT и Pillow. Для выхода закрой окно.

## Как создаётся текстура

make_environment.py ставит камеру в центр зеркального шара и смотрит
в сторону задней стены, вдоль -Z. Один кадр размером 256 × 256 сохраняется в PNG.
Сам зеркальный шар в этом кадре не рисуется.
Шести направлений, сборки сферической карты и расчёта лучей больше нет.

В main.py картинка загружается через load_texture, как остальные PNG.
GL_SPHERE_MAP автоматически выбирает текстурные координаты зеркального шара.
Это учебная имитация: используется одна обычная фотография сцены.
Она не содержит полного окружения, поэтому отражение не является точным.

## Файлы

- main.py — окно, камера, свет и отрисовка.
- make_environment.py — один снимок из центра зеркального шара и сохранение PNG.
- objects.py — стол, плоскости и сферы.
- scene.py — комната и расстановка предметов.
- textures.py — загрузка PNG.
- textures/environment.png — снимок для зеркального эффекта.
- textures/wood.png, earth.png, floor.png, wall.png — остальные картинки.

## Для защиты

На 3: текстура столешницы задаётся координатами четырёх вершин плоскости.
На 4: сфера глобуса строится вручную, текстурные координаты вычисляются
в sphere_vertex. gluNewQuadric не используется.
На 5: зеркальная сфера использует GL_SPHERE_MAP, GL_TEXTURE_GEN_S и
GL_TEXTURE_GEN_T. Картинка окружения подготовлена отдельно в упрощённом виде.

После изменения сцены снова запусти make_environment.py.
